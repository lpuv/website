## What it is

I have been doing CTFs and lab work since 2017. The TryHackMe Red Teamer Capstone was a simulated 17-host corporate network: enumeration, footholds, and lateral movement. I am in the top 1% of TryHackMe users. The profile is at [tryhackme.com/p/lunapuv](https://tryhackme.com/p/lunapuv).

I also write challenges. I wrote Cat Pictures 1 and 2 for TryHackMe. For McGill's CTF, I wrote a challenge that started with a Linux memory dump: use Volatility to find the binary, reverse it, and extract the flag. That CTF no longer exists, so the challenge is not linked.

## What's hard

The first shell is the easy part. The second host is where it gets interesting: pivoting, credential reuse, and knowing which service is the intended path versus a rabbit hole.

Writing a challenge is a different skill from solving one. You have to make the path discoverable, the difficulty honest, and the flag reachable without guessing.
